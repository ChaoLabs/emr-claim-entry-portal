# EMRTS Electronic Claim Entry Portal

A web-based claim entry and submission portal for capturing CMS-1500 professional claim information, storing claim data in PostgreSQL, and preparing the project for future ANSI X12 837P generation and Medicare submission workflow.

## Project Scope

This repository focuses on the Electronic Claim Entry & Submission Portal project. The initial implementation will support the first project area assigned to the CMS-1500 capture group:

- Build a web interface for capturing CMS-1500 claim information.
- Design a PostgreSQL database structure for claim entry data.
- Prepare documentation for architecture, database design, and future integration with ANSI X12 837P conversion.

## Initial Technology Direction

- Python
- Django
- PostgreSQL
- Mermaid diagrams for documentation
- C4 Model for architecture documentation

## Current Status
